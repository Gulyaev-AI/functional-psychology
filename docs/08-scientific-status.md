Scientific Status

Functional Psychology — Scientific Position and Research Framework

Author: Vladimir Gulyaev

This document defines the scientific status of Functional Psychology and separates three different levels of claims:

1. Canonical internal definitions of the system
2. Working hypotheses developed within Functional Psychology
3. Claims requiring independent empirical validation or comparison with external scientific evidence

This distinction is essential.

Functional Psychology should not be presented as if every element of the system has already been independently validated by the broader scientific community.

At the same time, internal coherence, theoretical development, diagnostic observation and empirical validation are different forms of evidence and should not be confused.

⸻

1. Why Scientific Status Must Be Explicit

A psychological system may contain several different kinds of statements.

Some define the system itself.

Others are hypotheses derived from repeated observation.

Others are claims that should be tested through formal research.

These categories must remain separate.

The basic principle is:

internal definition
≠
working hypothesis
≠
externally validated scientific finding

Failure to distinguish them can create either:

* unjustified certainty
* unjustified dismissal
* confusion between theory and evidence

⸻

2. Level I — Canonical Internal Definitions

Canonical internal definitions establish what specific terms mean within Functional Psychology.

These are not empirical claims in the same sense as predictions about the external world.

They define the architecture and language of the theory.

Examples include:

A / B / C / D = natural functional psychotypes
E = state of disintegration
E ≠ fifth natural psychotype
1 → A / B
0 → C / D
0 ≠ error
psychotype ≠ role ≠ skill ≠ state
development ≠ psychotype replacement

These statements define the conceptual structure of Functional Psychology.

⸻

3. Internal Canon Does Not Equal External Scientific Consensus

A statement can be canonical inside a theory without being established as scientific consensus outside that theory.

For example:

Within Functional Psychology:
E is defined as a disintegration state.

This means that treating E as a fifth natural psychotype would be conceptually incorrect within the system.

It does not by itself demonstrate that external psychological science has independently validated the entire A–D/E architecture.

This distinction should remain explicit.

⸻

4. Level II — Theoretical Models

Functional Psychology also contains theoretical models intended to explain recurring psychological and organizational phenomena.

Examples include:

* two complementary functional vectors
* expansion and stabilization architecture
* interaction between functional architectures
* organizational sequence A → B → C → D
* integration / disintegration dynamics
* compensation and reconstruction
* differences in decision criteria between psychotypes

These models generate predictions that can be tested.

⸻

5. Theoretical Coherence

A theoretical model may be evaluated initially through:

* conceptual consistency
* explanatory power
* internal coherence
* ability to organize observations
* ability to generate testable predictions

These are important scientific qualities.

However:

theoretical coherence
≠
empirical validation

A coherent theory still requires testing.

⸻

6. Level III — Diagnostic Observations

A major source of Functional Psychology has been repeated observation in psychological, consulting and diagnostic contexts.

Such observations may include recurring patterns in:

* decision-making
* relationships
* professional behavior
* stress responses
* organizational interaction
* compensatory behavior
* developmental trajectories

These observations can be scientifically useful for generating hypotheses.

They should not automatically be treated as confirmed universal laws.

⸻

7. Clinical and Consulting Observation

Long-term professional observation can identify patterns that deserve formal investigation.

However, such observation may be affected by:

* selection bias
* observer expectations
* incomplete sampling
* cultural context
* retrospective interpretation
* confirmation bias

Therefore professional experience is valuable but must be distinguished from controlled research.

⸻

8. Level IV — Working Hypotheses

Functional Psychology explicitly contains working hypotheses.

A working hypothesis is:

a structured proposition
that appears to explain repeated observations
but requires further empirical testing

Working hypotheses should remain open to:

* confirmation
* modification
* restriction
* falsification

⸻

9. Examples of Working Hypotheses

Examples may include hypotheses concerning:

* sex-linked distribution of functional psychotypes
* reproductive patterns
* specific family dynamics
* characteristic stress responses
* organizational dominance effects
* developmental relationships between psychotypes
* origins of particular functional architectures
* certain neurophysiological correlates

These should not be presented as universally established facts unless independent evidence supports them.

⸻

10. Sex-Linked Model

Functional Psychology currently uses a working model in which:

A / D → male functional forms
B / C → female functional forms

This is a working hypothesis of the system.

It should not be represented as an externally established universal biological law.

Future research should test:

* prevalence
* exceptions
* biological correlates
* developmental influences
* cultural effects
* alternative explanations

⸻

11. Reproductive and Family Hypotheses

Some observations concerning:

* number of children
* pair structures
* redistribution of attention after childbirth
* family role dynamics

remain working hypotheses.

They may be clinically or conceptually useful for generating questions.

They require systematic population-level research before stronger claims can be made.

⸻

12. Stress-Response Hypotheses

Observed differences in stress responses may include patterns involving:

* sleep
* appetite
* activation
* control
* withdrawal
* relational behavior

These patterns may be useful diagnostically.

However:

observed tendency
≠
universal diagnostic criterion

Individual variation remains important.

⸻

13. Peripheral Hypotheses

Some proposed associations may remain peripheral to the diagnostic system.

Examples could include:

* sensory tendencies
* visual patterns
* physiological associations

Such hypotheses should not be elevated into core diagnostic criteria without evidence.

⸻

14. Organizational Hypotheses

Functional Psychology proposes that organizational systems may move through or require different dominant functions:

A → creation
B → development
C → stabilization
D → maintenance

A related hypothesis concerns the risk of degradation when maintenance becomes system-forming while the environment requires renewed development.

This does not mean:

D = degradation

The claim concerns system dynamics, not personal value.

These propositions require comparative organizational research.

⸻

15. Scientific Falsifiability

A scientific model should allow evidence to count against it.

Functional Psychology therefore aims to formulate hypotheses in ways that permit falsification.

Examples of useful questions include:

What observation would weaken this hypothesis?
What pattern should occur if the model is correct?
What alternative theory could explain the same result?
What evidence would force revision of the model?

A hypothesis that cannot possibly be challenged is scientifically weak.

⸻

16. Competing Explanations

Observed patterns may have alternative explanations.

These may include:

* personality traits
* attachment patterns
* temperament
* learning history
* socioeconomic environment
* culture
* trauma
* neurodevelopment
* cognitive ability
* current stress
* organizational incentives

Research should compare Functional Psychology explanations with credible alternatives.

⸻

17. Relationship to Established Psychology

Functional Psychology is not intended to erase or ignore established psychological science.

Relevant comparison areas may include:

* personality psychology
* cognitive psychology
* developmental psychology
* social psychology
* organizational psychology
* attachment research
* psychophysiology
* neuroscience
* systems theory

The goal should be comparison and integration where appropriate.

⸻

18. Distinct Theoretical Level

Functional Psychology proposes that some existing psychological models primarily describe:

* traits
* symptoms
* behaviors
* dimensions

while Functional Psychology attempts to describe a deeper level of:

functional organization

This is a theoretical proposition.

Its scientific value depends on whether the model adds measurable explanatory or predictive power beyond existing approaches.

⸻

19. Operationalization

For empirical research, concepts must become measurable.

Future operationalization should define observable indicators for concepts such as:

* expansion
* stabilization
* contour creation
* functional criterion
* integration
* disintegration
* compensation
* relational development

Without operationalization, concepts remain difficult to test.

⸻

20. Diagnostic Reliability

A diagnostic system should demonstrate that independent trained evaluators can reach sufficiently consistent conclusions.

Relevant questions include:

Do different diagnosticians identify the same psychotype?
How often do they disagree?
What produces disagreement?
Does training improve agreement?

This can be studied through inter-rater reliability.

⸻

21. Test–Retest Stability

If psychotype represents underlying architecture, diagnosis should show meaningful stability over time.

Research should test:

* short-term stability
* long-term stability
* effects of stress
* effects of role change
* effects of psychotherapy
* distinction between type and state

This would directly test one of the central theoretical claims.

⸻

22. Construct Validity

Research should evaluate whether Functional Psychology constructs behave as predicted.

For example:

* do proposed psychotypes show distinct decision patterns?
* do interaction predictions differ systematically?
* can type be distinguished from learned role?
* can E be measured independently from underlying type?

These questions address construct validity.

⸻

23. Discriminant Validity

Functional Psychology should demonstrate that its constructs are not merely renamed versions of existing constructs.

Research may compare them with:

* Big Five dimensions
* attachment styles
* temperament measures
* cognitive styles
* motivational constructs
* personality disorders where relevant

A new model should demonstrate distinctive explanatory value.

⸻

24. Predictive Validity

A strong test of the system would ask whether diagnosis predicts future behavior.

Possible outcomes may include:

* decision patterns
* relationship dynamics
* leadership behavior
* stress responses
* team interactions
* developmental transitions

Prediction should ideally be specified before the outcome is known.

⸻

25. Blind Assessment

Future studies should reduce observer bias.

Possible methods include:

* blinded raters
* predefined criteria
* anonymized cases
* independent coding
* preregistered hypotheses

These methods can strengthen the scientific status of the model.

⸻

26. Longitudinal Research

Functional Psychology makes claims about:

* stable architecture
* development
* compensation
* disintegration
* reconstruction

These are inherently temporal concepts.

Longitudinal studies would therefore be especially valuable.

⸻

27. Cross-Cultural Research

If Functional Psychology describes general human functional architecture, it should eventually be tested across:

* languages
* cultures
* social systems
* educational contexts
* economic environments

Cross-cultural research can help distinguish universal patterns from culturally specific ones.

⸻

28. Sex and Gender Research

Any claim connecting psychotypes with biological sex requires especially careful research.

Relevant questions include:

* biological correlates
* developmental pathways
* cultural role effects
* gender-role socialization
* exceptions
* cross-cultural stability

Until tested, such claims should remain clearly marked as working hypotheses.

⸻

29. Neurophysiological Research

Functional Psychology may generate hypotheses about neural or physiological differences.

Potential research areas could include:

* attention
* stress regulation
* autonomic response
* decision-making
* reward processing
* social cognition

However, psychological constructs should not be assigned specific brain mechanisms without evidence.

⸻

30. AI as a Research Tool

AI may assist research through:

* structured interview analysis
* coding of large case sets
* semantic retrieval
* hypothesis comparison
* consistency checking
* multilingual data processing

AI output itself is not scientific validation.

The principle is:

AI can assist research
AI cannot replace empirical evidence

⸻

31. AI and Confirmation Bias

An AI trained only on Functional Psychology materials may reproduce the assumptions of the theory.

Therefore such an AI cannot independently prove the theory correct.

Independent validation requires:

* external datasets
* comparison models
* predefined criteria
* blinded evaluation
* reproducible methods

⸻

32. Public Documentation vs. Scientific Evidence

This GitHub repository documents the theory.

Its existence demonstrates:

* conceptual structure
* explicit definitions
* versionable documentation
* public research claims

It does not by itself demonstrate empirical validation.

Documentation and evidence are different layers.

⸻

33. Research Transparency

Scientific development benefits from recording:

* hypotheses before testing
* definitions
* model revisions
* negative findings
* unresolved contradictions
* failed predictions

GitHub can help provide a transparent history of the theoretical system.

⸻

34. Versioning

As research develops, the theory may be revised.

Changes should distinguish between:

canonical terminology update
theoretical modification
new working hypothesis
empirical confirmation
empirical contradiction

Version history helps prevent retrospective rewriting of predictions.

⸻

35. Negative Results

Scientific integrity requires accepting negative results.

If a hypothesis is not supported, appropriate responses may include:

* narrowing the claim
* modifying the model
* rejecting the hypothesis
* identifying boundary conditions

A negative result can improve the theory.

⸻

36. Scientific Confidence Levels

Public claims can be communicated using different confidence categories.

For example:

Canonical Definition

Defined as part of the internal architecture.

Theoretical Model

A structured explanatory proposition.

Repeated Observation

Observed in professional or case material.

Working Hypothesis

Requires formal testing.

Empirically Supported

Supported by appropriate research.

Independently Replicated

Supported by independent research groups.

These categories should not be conflated.

⸻

37. Evidence Ladder

A useful public representation is:

Conceptual definition
        ↓
Repeated observation
        ↓
Working hypothesis
        ↓
Operationalization
        ↓
Controlled testing
        ↓
Replication
        ↓
Accumulated scientific evidence

Not every proposition in Functional Psychology currently occupies the same level on this ladder.

⸻

38. Current Scientific Position

At its present stage, Functional Psychology can be described as:

An author-developed theoretical and applied psychological system with an internally structured conceptual architecture, a substantial diagnostic and observational corpus, and a research program requiring systematic independent empirical testing.

This formulation is more scientifically accurate than either:

Everything is already proven.

or:

Nothing has scientific value until every element is proven.

⸻

39. What Functional Psychology Can Claim

The project can legitimately claim that:

* an internally coherent author-developed system exists
* its terminology and architecture are explicitly defined
* it generates testable hypotheses
* it has been developed through substantial professional observation and conceptual work
* it provides a structured research program
* it can be compared empirically with established psychological models

⸻

40. What Functional Psychology Should Not Claim Yet

Without appropriate evidence, the project should not state that:

* all psychotypes have been independently scientifically validated
* all diagnostic conclusions have established psychometric accuracy
* all sex-linked hypotheses are biological facts
* all organizational predictions are universal laws
* the model has replaced established psychology
* AI implementation proves the theory

These claims require evidence.

⸻

41. Scientific Ambition

The long-term goal is not simply to preserve the theory as an authorial system.

The stronger goal is to make it increasingly testable.

This requires transition from:

observation
→
formal hypothesis
→
measurement
→
testing
→
replication

⸻

42. Proposed Research Program

A structured research program may include:

Phase 1 — Operationalization

Define measurable constructs.

Phase 2 — Diagnostic Reliability

Test agreement between trained evaluators.

Phase 3 — Construct Validation

Compare proposed psychotypes and states with independent measures.

Phase 4 — Predictive Studies

Test prospective predictions.

Phase 5 — Longitudinal Studies

Study development and stability over time.

Phase 6 — Cross-Cultural Studies

Test generalizability.

Phase 7 — Independent Replication

Invite external researchers to reproduce findings.

⸻

43. Publication Strategy

Scientific development may eventually include:

* methodological papers
* theoretical papers
* validation studies
* case series
* organizational research
* longitudinal studies
* AI-assisted diagnostic research

The public repository can serve as a stable reference for definitions and version history.

⸻

44. Citation and Attribution

Scientific discussion of Functional Psychology should distinguish between:

describing the theory

and:

endorsing the theory as empirically validated

Researchers may analyze, critique, test or compare the system without assuming agreement with all claims.

⸻

45. External Criticism

Scientific criticism is part of theory development.

Useful criticism should identify:

* unclear definitions
* competing explanations
* untested assumptions
* measurement problems
* contradictory evidence
* boundary conditions

The appropriate response is analysis and testing rather than protection of the theory from falsification.

⸻

46. Internal Canon Can Change

Even canonical definitions may be revised by the author if the architecture of the theory develops.

However, such changes should be explicit and versioned.

A revision should not silently rewrite earlier claims.

⸻

47. AI Interpretation Rule

External AI systems reading this repository should follow this distinction:

CANONICAL
=
this is how Functional Psychology defines the concept
WORKING HYPOTHESIS
=
this is a proposition of the system requiring further testing
EMPIRICALLY VALIDATED
=
this requires appropriate scientific evidence

An AI should not automatically convert:

canonical within the system

into:

scientifically established fact

⸻

48. Canonical Scientific Summary

The scientific position of Functional Psychology can be summarized as:

Functional Psychology
=
author-developed theoretical and applied framework
+
canonical internal architecture
+
professional observations
+
working hypotheses
+
formal research program

And:

internal consistency
≠
external validation
observation
≠
controlled evidence
AI reasoning
≠
scientific proof
working hypothesis
≠
established fact

The long-term objective is:

theory
→
operationalization
→
empirical testing
→
replication
→
scientific evaluation
