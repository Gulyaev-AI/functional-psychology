Encyclopedia of Functional Psychology

Canonical Corpus of the System

Author: Vladimir Gulyaev

The Encyclopedia of Functional Psychology is the principal theoretical and methodological corpus of Functional Psychology.

It is organized as a three-volume system.

The encyclopedia defines and develops:

* the conceptual foundations of Functional Psychology
* the architecture of psychotypes A–D
* the status of E as a state of disintegration
* integration and disintegration
* compensation and reconstruction
* interpersonal interaction
* organizational systems
* functional diagnostics
* research hypotheses
* scientific status
* AI-oriented knowledge architecture

The full texts of the encyclopedia are not published in this public repository.

This section documents their role, structure and relationship to the public and private layers of the Functional Psychology ecosystem.

⸻

2. Why a Canonical Corpus Is Necessary

A developing theoretical system can accumulate:

* early formulations
* revised terminology
* working notes
* public explanations
* case discussions
* AI-generated summaries
* historical versions

Without a clear hierarchy, contradictions may emerge.

The encyclopedia therefore provides a stable reference point.

The principle is:

one system
→
one authoritative canonical corpus

Volume I

3. Foundations of Functional Psychology

Volume I provides the fundamental entry point into the system.

* conceptual foundations
* terminology
* general architecture
* functional differences
* relationship between psychotype and state
* development
* stress

Volume I is designed to remain the most accessible foundational volume.

4. Function of Volume I

Volume I answers questions such as:

What is Functional Psychology?
What is a functional psychotype?
What is the difference between type and state?
What are the two functional vectors?
How do A–D relate to E?
How does development occur?

It provides the conceptual vocabulary required for the later volumes.

10. Canonical Consistency

All three volumes follow the same fundamental architecture:

1 → A / B
0 → C / D
E → disintegration state

And the same core distinctions:

E ≠ fifth natural psychotype
0 ≠ error
psychotype ≠ role ≠ skill ≠ state
development ≠ psychotype replacement

These principles should remain consistent throughout the encyclopedia.

⸻

11. E Across the Encyclopedia

A central editorial requirement is that E must not be interpreted as equivalent to A–D.

The correct structure is:

Underlying architecture:
A / B / C / D
Functional condition:
integration ↔ disintegration

E belongs to the state dimension.

⸻

12. Two-Vector Architecture

The encyclopedia uses the two-vector model:

VECTOR 1
A / B
Expansion · Search · Development
VECTOR 0
C / D
Preservation · Stabilization · Maintenance

This model is functional and non-hierarchical.

Neither vector is superior.

⸻

13. Individual and Relational Levels

The encyclopedia does not treat psychotypes only as isolated categories.

It develops at least two analytical levels:

individual architecture

and:

interaction architecture

This allows the system to study both the person and what emerges between people.

15. Organizational Layer

The encyclopedia extends Functional Psychology to organizations.

One public high-level model is:

A → creation / expansion
B → development
C → stabilization / mastery
D → maintenance

This model is analyzed as a dynamic organizational cycle rather than a hierarchy of people.

23. Why Full Volumes Are Not Published Here

The complete volumes contain a much larger body of original authorial material.

Public release through GitHub could:

* separate material from its intended publication context
* create uncontrolled copies
* enable unauthorized derivative products
* facilitate uncontrolled AI training
* weaken version control
* expose proprietary diagnostic knowledge

For these reasons, the public repository remains a documentation layer rather than a complete digital edition of the encyclopedia.
